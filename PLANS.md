# Execution plan and gates

## Phase 0 — baseline integrity and exact normalization

### Objectives

- Verify package, source hash, environment, and repository state.
- Freeze the initial periodic gradient-flow model.
- Freeze \(\lambda_N=\beta_NN^{s/d-1}\), the old condition, subcritical and critical regimes.
- Freeze empirical-measure, deleted-diagonal, Fourier, noise, and fluctuation normalizations.
- Independently reconstruct the first-order duality identity.
- Classify every statement in `note_v2.pdf` by evidence type.

### Gate M0

No unresolved normalization conflict; exact duality identity reconstructed twice; initial state and source ledgers complete.

## Phase 1 — exact quadratic corrector

### Objectives

- Derive the two-body generator identity from explicit particle sums.
- Identify the full pair linearized operator.
- Display force coupling, background-response terms, Itô traces, diagonal counterterms, martingale, and quadratic variation.
- Compare U-statistic, empirical-measure, and BBGKY derivations.
- Test \(N=2,3\), smooth kernel, homogeneous background, and affine velocity.

### Competing routes

- Route A: U-statistic/Hoeffding algebra.
- Route B: pair Poisson/Stein equation.
- Route C: BBGKY/cumulant derivation.
- Route H: coefficient and obstruction falsification.

### Gate M1

One frozen quadratic identity, all coefficients independently reconstructed, no unresolved diagonal/Itô term, hostile self-audit passed. Independent status still requires isolated reconstruction.

## Phase 5 — singular subcritical theorem

### Objectives

Split into:

1. \(2s<d\): Hilbert–Schmidt quadratic/Fock route;
2. \(2s=d\): logarithmic counterterm;
3. \(2s>d\): finite-particle corrector, pair field, or scale-by-scale renormalization.

For each branch:

- prove uniform regularized corrector estimates;
- identify every counterterm;
- prove cutoff removal;
- establish static-to-dynamic inputs;
- close the theorem for arbitrary \(\lambda_N\to0\), without a polynomial gap.

### Gate M5

Full singular subcritical theorem with explicit centering and no hidden old restriction.
