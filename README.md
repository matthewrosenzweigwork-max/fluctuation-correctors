# HOCF-RIESZ

Autonomous Astra campaign for second- and higher-order correctors to fluctuations in Coulomb/Riesz mean-field dynamics.

Start with `README_FIRST.md`. The scientific specification is `MASTER_PROMPT.md`; repository governance is `AGENTS.md` and `CAMPAIGN_PROTOCOLS.md`; launch with `KICKOFF_PROMPT_ULTRA.md` in an Astra Ultra root session.

The campaign distinguishes:

\[
\beta_NN^{2s/d-1}\to0
\quad\text{(existing energy-floor closure)},
\]
\[
\lambda_N:=\beta_NN^{s/d-1}\to0
\quad\text{(full subcritical target)},
\]
and
\[
\lambda_N\to\lambda\in(0,\infty)
\quad\text{(critical target)}.
\]

Run `python3 scripts/verify_campaign.py` before work.
