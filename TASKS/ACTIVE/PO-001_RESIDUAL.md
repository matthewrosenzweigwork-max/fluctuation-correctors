## First bounded assertion

Fix d,T and a smooth real even g and smooth V on the unit torus. For each N>=2 and beta_N>0 use the frozen gradient diffusion and its smooth deterministic mean-field solution mu^N, initialized by a fixed smooth positive mu_0. Start the particles iid with law mu_0. Let f^N solve the full one-body backward equation and Phi^N the zero-terminal pair equation of COR-001 for a fixed smooth terminal test. For this first bounded test, set r=4d+12 and assume there is a finite A independent of N and time such that sup_{N,t in [0,T]} (||mu^N_t||_{C^r(T^d)}+||f^N_t||_{C^r(T^d)}+||Phi^N_t||_{C^r(T^{2d})}) <= A, using the maximum norm over componentwise spatial derivatives of total order at most r. This deliberately strong smooth hypothesis is explicit; it is not a derived background estimate or a restriction imposed on the eventual singular target. Any reduction in required regularity must be proved and recorded as a new version.

Put sigma_N=min(sqrt(N beta_N),sqrt N). Prove, for every such temperature sequence and data satisfying those uniform bounds,

1. sigma_N E|P_N[Phi^N_0]| -> 0;
2. sigma_N E|integral_0^T U_3[C Phi^N_t] dt| -> 0;
3. sigma_N^2 E[M_Phi]_T -> 0, together with sigma_N^2 E|[M_f,M_Phi]_T| -> 0.

The lower drift contractions are separately bounded by C sigma_N/N under these assumptions. If a term above survives, give a counterexample within this exact iid class and formulate its correct retained limit. A first-moment signed cancellation cannot replace the absolute-value estimates.

Exact negation: fixed permitted smooth data and a sequence of N,beta_N with the stated uniform norms for which at least one of these nonnegative quantities has positive limsup (or a purported estimate uses an unproved uniform constant). No claim is made for arbitrary initial laws; clustered deterministic configurations already preclude such a transfer.
